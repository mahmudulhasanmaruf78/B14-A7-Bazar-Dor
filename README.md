# 🛒 বাজার দর (BazarDor) — নিত্যপ্রয়োজনীয় পণ্যের লাইভ বাজার দর ও মূল্য বিশ্লেষণ

> দৈনন্দিন পরিবারের বাজেট পরিকল্পনা ও নিত্যপ্রয়োজনীয় পণ্যের নির্ভরযোগ্য বাজার বিশ্লেষণের উন্মুক্ত প্ল্যাটফর্ম।

## 📌 প্রকল্পের পরিচিতি (Project Overview)

**বাজার দর (BazarDor)** হলো একটি আধুনিক, দ্রুতগতির ও রেস্পন্সিভ ওয়েব অ্যাপ্লিকেশন, যা প্রতিদিনের চাল, ডাল, তেল, সবজি, মাছ, মাংস ও মসলার সঠিক ও হালনাগাদ বাজার মূল্য এক নজরে উপস্থাপন করে। এটি ক্রেতা ও সাধারণ মানুষদের সারা দেশের বিভিন্ন বিভাগ ও পাইকারি/খুচরা বাজারের তুলনামূলক দর পর্যবেক্ষণ এবং সঠিক মূল্যে কেনাকাটার সিদ্ধান্ত নিতে সহায়তা করে।

- **লাইভ প্রিভিউ:** [BazarDor Live](https://bazardor.vercel.app)
- **গিটহাব রিপোজিটরি:** [GitHub Repository](https://github.com/your-username/bazardor)

## ✨ প্রধান ৫টি বৈশিষ্ট্য (Key Features)

1. **রিয়েল-টাইম লাইভ প্রাইস ট্র্যাকার ও মার্কেট টিকার (Live Price Ticker Marquee):**
   - ওয়েবসাইটের শীর্ষভাগে স্বয়ংক্রিয়ভাবে চলমান মূল্য পরিবর্তনের ইনফিনিট স্ক্রলিং স্ট্রিপ।
   - পণ্যের নাম, আজকের দর, একক এবং মূল্যবৃদ্ধির (▲) বা হ্রাসের (▼) শতকরা হার লাইভ প্রদর্শন করে।

2. **দৈনন্দিন বাজার পরিবর্তনের শীর্ষ পণ্যসমূহ (Top Risers & Fallers):**
   - **আজ দাম বেড়েছে (▲):** গতকালের তুলনায় মূল্যবৃদ্ধির শীর্ষ ৬টি পণ্য।
   - **আজ দাম কমেছে (▼):** গতকালের তুলনায় মূল্যহ্রাসের শীর্ষ ৬টি পণ্য।
   - বাংলা সংখ্যা এবং রঙিন নির্দেশক (Green for up, Red for down) দিয়ে সুস্পষ্ট ভিজ্যুয়ালাইজেশন।

3. **ক্যাটাগরি ফিল্টারিং ও সঠিক বাংলা সংখ্যাভিত্তিক সাজানো (Bengali Numeral Sorting):**
   - চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম-দুধ ও মসলার মতো ক্যাটাগরিভিত্তিক দ্রুত ফিল্টারিং।
   - **সাজান (Sorting Control):** ডিফল্ট, দাম: কম থেকে বেশি, এবং দাম: বেশি থেকে কম। বাংলা সংখ্যাকে সঠিকভাবে সাংখ্যিক মানে রূপান্তর করে নিখুঁত সর্টিং নিশ্চিত করা হয়েছে।

4. **বাজারভিত্তিক বিস্তারিত দর ও সংরক্ষিত রুট (Protected Product Details & Market Breakdown):**
   - প্রতিটি পণ্যের বিস্তারিত পৃষ্ঠায় সর্বনিম্ন, সর্বোচ্চ এবং জাতীয় গড় মূল্যের সামারি কার্ড।
   - **বাজারভিত্তিক আজকের দাম:** কারওয়ান বাজার, মিরপুর, চট্টগ্রাম, রাজশাহী, সিলেটসহ বিভিন্ন বিভাগীয় বাজারের বিস্তারিত মূল্য তালিকা।
   - অথেন্টিকেশন সংরক্ষিত রুট: লগইন ছাড়া বিস্তারিত পৃষ্ঠায় প্রবেশ করতে চাইলে স্বয়ংক্রিয় রিডাইরেক্ট এবং তথ্যবহুল টোস্ট নোটিফিকেশন।

5. **BetterAuth ভিত্তিক প্রমাণীকরণ ও প্রোফাইল আপডেট (BetterAuth & User Profile Update):**
   - ইমেইল/পাসওয়ার্ড ও সোশ্যাল লগইন (গুগল ও গিটহাব) সুবিধা।
   - **তথ্য আপডেট ফিচার (Challenge C3):** প্রোফাইল পৃষ্ঠা থেকে ব্যবহারকারী তাঁর নাম ও তথ্য তাৎক্ষণিকভাবে হালনাগাদ করতে পারেন।
   - প্রতিটি ক্রিয়া ও সতর্কতার জন্য `react-hot-toast` ইন্টিগ্রেশন।

## 🛠️ ব্যবহৃত প্রযুক্তিসমূহ (Technologies Used)

| প্রযুক্তি | ব্যবহার ও উদ্দেশ্য |
| :--- | :--- |
| **Next.js 16 (App Router)** | আধুনিক ফুলস্ট্যাক আর্কিটেকচার, SSR/ISR ও পেজ রাউটিং |
| **React 19 & TypeScript** | টাইপ-সেফ কম্পোনেন্ট ডেভেলপমেন্ট ও স্টেট ম্যানেজমেন্ট |
| **Tailwind CSS & DaisyUI** | আধুনিক রেসপন্সিভ স্টাইলিং ও প্রিমিয়াম ডিজাইন সিস্টেম |
| **BetterAuth** | ব্যবহারকারী প্রমাণীকরণ ও প্রোফাইল ব্যবস্থাপনা |
| **React Hot Toast** | মসৃণ ও ইউজার-ফ্রেন্ডলি টোস্ট নোটিফিকেশন |
| **Lucide React** | আধুনিক ও স্কেলযোগ্য ভেক্টর আইকন |
| **Hind Siliguri Font** | বাংলা ফন্টের স্পষ্ট ও নান্দনিক টাইপোগ্রাফি |

## 🚀 লোকাল সেটআপ ও ইনস্টলেশন (Getting Started)

### ১. রিপোজিটরি ক্লোন করুন:
```bash
git clone https://github.com/your-username/bazardor.git
cd bazardor
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ৩. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন করে অ্যাপ্লিকেশনটি দেখুন।

### ৪. প্রোডাকশন বিল্ড তৈরি করুন:
```bash
npm run build
npm run start
```

```
bazardor/
├── public/                 # স্থির ফাইল ও ইমেজ (bazar-hero.png, logo-icon.png)

│   │   ├── api/auth/       # BetterAuth API হ্যান্ডলার
│   │   ├── category/[slug] # ক্যাটাগরি ও ফিল্টারিং পৃষ্ঠা
│   │   ├── product/[slug]  # সংরক্ষিত পণ্যের বিস্তারিত পৃষ্ঠা
│   │   ├── profile/        # প্রোফাইল ও তথ্য আপডেট (C3)
│   │   ├── signin/         # সাইন ইন পৃষ্ঠা
│   │   ├── signup/         # সাইন আপ পৃষ্ঠা
│   │   ├── layout.tsx      # রুট লেআউট ও মেটাডাটা
│   │   ├── page.tsx        # হোম পেজ (টিকার, হিরো, রাইজার্স, ফলার্স, সব পণ্য)
│   │   └── not-found.tsx   # কাস্টম ৪০৪ পৃষ্ঠা
│   ├── components/         # মডুলার ইউআই কম্পোনেন্টস
│   │   ├── Navbar.tsx      # বাংলা তারিখ, লোগো, ক্যাটাগরি বার ও ড্রপডাউন
│   │   ├── PriceTicker.tsx # ইনফিনিট প্রাইস টিকার
│   │   ├── Hero.tsx        # হিরো ব্যানার ও স্ক্রল সিটিএ
│   │   ├── ProductCard.tsx # পণ্যের কার্ড
│   │   ├── SortDropdown.tsx# বাংলা সংখ্যাভিত্তিক সর্টিং
│   │   ├── Skeleton.tsx    # লোডিং অ্যানিমেশন
│   │   └── Footer.tsx      # ফুটার
│   ├── context/            # AuthContext স্টেট ম্যানেজমেন্ট
│   └── lib/                # API হ্যান্ডলার, বাংলা সংখ্যা ও তারিখ ইউটিলিটি
└── tailwind.config.js      # টেইলউইন্ড ও ডেইজিইউআই কনফিগারেশন
```
