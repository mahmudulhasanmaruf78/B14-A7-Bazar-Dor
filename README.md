> দৈনন্দিন পরিবারের বাজেট পরিকল্পনা ও নিত্যপ্রয়োজনীয় পণ্যের নির্ভরযোগ্য বাজার বিশ্লেষণের উন্মুক্ত প্ল্যাটফর্ম।

## 📌 প্রকল্পের পরিচিতি (Project Overview)

**বাজার দর (BazarDor)** হলো একটি আধুনিক, উচ্চগতিসম্পন্ন ও সম্পূর্ণ রেসপন্সিভ ওয়েব অ্যাপ্লিকেশন, যা প্রতিদিনের চাল, ডাল, তেল, সবজি, মাছ, মাংস ও মসলার সঠিক ও হালনাগাদ বাজার মূল্য এক নজরে উপস্থাপন করে। এটি সাধারণ ক্রেতা ও সচেতন নাগরিকদের সারা দেশের বিভিন্ন পাইকারি ও খুচরা বাজারের তুলনামূলক দর পর্যবেক্ষণ এবং সঠিক মূল্যে কেনাকাটার সিদ্ধান্ত নিতে সহায়তা করে।

- 🌐 **লাইভ ডিপ্লয়মেন্ট (Live URL):** [https://b14-a7-bazar-dor-gamma.vercel.app](https://b14-a7-bazar-dor-gamma.vercel.app)
- 💻 **গিটহাব রিপোজিটরি (GitHub Repository):** [https://github.com/mahmudulhasanmaruf78/B14-A7-Bazar-Dor](https://github.com/mahmudulhasanmaruf78/B14-A7-Bazar-Dor)

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features & Highlights)

### ১. রিয়েল-টাইম লাইভ প্রাইস টিকার (Live Marquee Ticker - Challenge C2)
- ওয়েবসাইটের শীর্ষে চলমান ইনফিনিট মারকুই স্ক্রলিং স্ট্রিপ।
- পণ্যের নাম, একক, বর্তমান বাজারদর এবং মূল্যবৃদ্ধি (▲) বা হ্রাসের (▼) শতকরা হার লাইভ প্রদর্শিত হয়।
- মাউস হোভারে স্ট্রিপটি স্মুথলি পজ (Pause on hover) হয়।

### ২. শীর্ষ মূল্য পরিবর্তনকারী পণ্যসমূহ (Top Risers & Fallers)
- **আজ দাম বেড়েছে (▲):** গতকালের তুলনায় মূল্যবৃদ্ধির শীর্ষ ৬টি পণ্য।
- **আজ দাম কমেছে (▼):** গতকালের তুলনায় মূল্যহ্রাসের শীর্ষ ৬টি পণ্য।
- প্রতিটি কার্ডে বাংলা সংখ্যায় দর, শতকরা পরিবর্তন এবং রঙ-সংকেত (সবুজ ও লাল)।

### ৩. ক্যাটাগরি ফিল্টারিং ও বাংলা সংখ্যাভিত্তিক সঠিক সাজানো (Sorting - Challenge C1)
- চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম-দুধ ও মসলার মতো আইকনযুক্ত ক্যাটাগরি বার।
- **উন্নত বাংলা সর্টিং:** ডিফল্ট, দাম: কম থেকে বেশি, এবং দাম: বেশি থেকে কম। বাংলা সংখ্যাকে (`১২৩` ➔ `123`) সাংখ্যিক মানে রূপান্তর করে নিখুঁত গাণিতিক সর্টিং সম্পন্ন করা হয়েছে।
- লাইভ সার্চ বক্সের মাধ্যমে যেকোনো পণ্য তাৎক্ষণিকভাবে খুঁজে পাওয়ার সুবিধা।

### ৪. বাজারভিত্তিক বিশদ মূল্য তালিকা ও প্রটেক্টেড রুট (Product Details & Market Breakdown)
- প্রতিটি পণ্যের জন্য পৃথক সুরক্ষিত বিস্তারিত পেজ (`/product/[slug]`)।
- অননুমোদিত ইউজার প্রবেশ করতে চাইলে স্বয়ংক্রিয়ভাবে সাইন-ইন পেজে রিডাইরেক্ট এবং তথ্যবহুল টোস্ট নোটিফিকেশন প্রদর্শন।
- বিস্তারিত পেজে জাতীয় সর্বনিম্ন, সর্বোচ্চ ও গড় মূল্যের সামারি কার্ড।
- **Figma ডিজাইন অনুসারী ৫-কলাম বাজার টেবিল:** `বাজার`, `বিভাগ`, `সর্বনিম্ন`, `সর্বাধিক` এবং `গড়` (বাংলা সংখ্যা ও দশমিক ফরম্যাটিং সহ)।

### ৫. মাল্টি-প্রোভাইডার প্রমাণীকরণ (BetterAuth + MongoDB Atlas)
- ইমেইল ও পাসওয়ার্ডের মাধ্যমে সাইন ইন এবং সাইন আপ।
- **সোশ্যাল ওঅথ (OAuth):** গুগল (Google) এবং গিটহাব (GitHub) ওঅথ লগইন সুবিধা।
- MongoDB Atlas ডেটাবেজে সেশন ও অ্যাকাউন্ট সংরক্ষণ।

### ৬. প্রোফাইল ও তথ্য আপডেট (Profile Management - Challenge C3)
- প্রোফাইল ভিউ পেজ (`/profile`)।
- **তথ্য পরিবর্তন রাউট (`/profile/update`):** ইউজারের নাম ও প্রাসঙ্গিক তথ্য সহজে এডিট এবং ডেটাবেজে সংরক্ষণ।

### ৭. রেসপন্সিভ ডিজাইন ও কাস্টম ৪০৪ পেজ
- মোবাইল, ট্যাবলেট ও ডেস্কটপের জন্য সম্পূর্ণ অপ্টিমাইজড ড্রয়ার ও নেভিগেশন।
- কোনো ভুল রুটে প্রবেশ করলে ইউজার-ফ্রেন্ডলি কাস্টম ৪০৪ পেজ (`/not-found.tsx`) হোমপেজে ফিরে আসার সুযোগ দেয়।

## 🛠️ ব্যবহৃত প্রযুক্তিসমূহ (Technologies Used)

| প্রযুক্তি | ভূমিকা ও বিবরণ |
| :--- | :--- |
| **Next.js 16 (App Router)** | আধুনিক ফুলস্ট্যাক আর্কিটেকচার, SSR/ISR ক্যাশিং ও টার্বোপ্যাক |
| **React 19 & TypeScript** | টাইপ-সেফ কম্পোনেন্ট ডেভেলপমেন্ট ও স্টেট ম্যানেজমেন্ট |
| **Tailwind CSS v3 & DaisyUI v4** | আধুনিক ইউটিলিটি ক্লাস ও প্রিমিয়াম ডিজাইন সিস্টেম |
| **MongoDB Atlas** | ক্লাউড নোএসকিউএল ডেটাবেজ (ডাইরেক্ট রেপ্লিকা সেট সংযোগ সহ) |
| **BetterAuth** | আধুনিক সিকিউর অথেন্টিকেশন ইঞ্জিন (MongoDB অ্যাডাপ্টার সহ) |
| **OAuth Providers** | Google Cloud Console ও GitHub Developer Apps |
| **React Hot Toast** | মসৃণ ও প্রিমিয়াম টোস্ট নোটিফিকেশন সিস্টেম |
| **Lucide React** | স্কেলযোগ্য ভেক্টর আইকন কালেকশন |
| **Hind Siliguri Font** | বাংলা ভাষার জন্য দৃষ্টিনন্দন গুগল ফন্ট |

## ⚙️ এনভায়রনমেন্ট ভেরিয়েবলস (.env Setup)

প্রজেক্টটি সঠিকভাবে চালাতে রুট ডিরেক্টরিতে একটি `.env` ফাইল তৈরি করুন এবং নিচের মানগুলো সেট করুন:

```env
# BetterAuth Configuration
BETTER_AUTH_SECRET=your_better_auth_secret_32_characters
BETTER_AUTH_URL=http://localhost:3000

# MongoDB Atlas Connection
MONGODB_URI=your_mongodb_connection_string
MONGODB_DB_NAME=bazardor

# GitHub OAuth
GITHUB_CLIENT_ID=your_github_client_id
GITHUB_CLIENT_SECRET=your_github_client_secret

# Google OAuth
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret

# Live API URL
NEXT_PUBLIC_API_URL=https://openapi.programming-hero.com/api/bazardor
```

## 🚀 লোকাল সেটআপ ও ইনস্টলেশন (Getting Started)

### ১. রিপোজিটরি ক্লোন করুন:
```bash
git clone https://github.com/mahmudulhasanmaruf78/B14-A7-Bazar-Dor.git
cd B14-A7-Bazar-Dor
```

### ২. প্যাকেজসমূহ ইনস্টল করুন:
```bash
npm install
```

### ৩. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন করে প্রজেক্টটি ব্রাউজ করুন।

### ৪. প্রোডাকশন বিল্ড পরীক্ষা করুন:
```bash
npm run build
npm run start
```

│   │   ├── Hero.tsx        # হিরো ব্যানার সেকশন (Figma ডিজাইন অনুযায়ী)
